# Task 3 – CRUD Console Application 📋

This is a console-based CRUD application that allows users to create, read, update, and delete tasks using a Java ArrayList.

## 📌 Features
- Add, view, edit, and delete tasks
- Console menu-driven interface
- Object-oriented approach with a Task model

## 🛠️ Technologies Used
- Java
- Maven
- IntelliJ IDEA

## 🚀 How to Run
1. Open the project in IntelliJ
2. Run `TaskManager.java` from the `com.cognifyz` package
